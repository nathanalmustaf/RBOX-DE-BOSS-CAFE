# RBOX DEBOSS CAFE — Smart POS

Demo web-based cashier system for RBOX DEBOSS CAFE. Built with plain HTML, CSS, and JavaScript. No build step required.


## Run locally
Open `index.html` in a modern browser.


## Deploy to GitHub Pages
1. Create a GitHub repository (e.g. `rbox-deboss-pos`).
2. Upload the files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the Pages URL to appear.

## Demo notes
- Owner demo PIN: `2468` (change it in Owner settings before testing).
- Data is saved in the current browser using localStorage. It is not shared across devices/users.
- QRIS screen is a placeholder, not a live payment QR. Confirm payments manually in this demo.
- This is a prototype, not secure production POS software. Owner PIN is client-side and data can be edited/cleared by browser users.
